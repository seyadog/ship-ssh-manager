# ship

Gestor de conexiones SSH para la terminal (TUI moderna, con ratón). Guarda servidores en carpetas y abre cada sesión en una pestaña. Pensado como alternativa ligera a Tabby.

Estado: en desarrollo (Fase 1). Arquitectura en [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Desarrollo

Requiere Rust estable y un cliente `ssh` en el PATH.

```sh
cargo run
```
